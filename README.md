<h1 align="center">📱 Expo JWT Auth Frontend</h1>
<p align="center">React Native Expo frontend uygulaması, Laravel API ile JWT tabanlı authentication için</p>

---

## 🎯 Proje Hakkında

Bu proje, React Native Expo kullanılarak geliştirilmiş bir mobil uygulamanın **frontend** kısmıdır.  
Arka planda Laravel ile yazılmış bir API ve MySQL veri tabanı kullanılmaktadır.  
JWT authentication yapısı üzerinden kullanıcıların giriş, kayıt ve yetkilendirme işlemleri yapılmaktadır.  

İstekler `axios` kütüphanesiyle API'ye gönderilmekte, kullanıcı bilgileri ise `AsyncStorage` ile cihazda saklanmaktadır.

---

## 🛠️ Kullanılan Teknolojiler

- React Native Expo  
- JavaScript (ES6+)  
- Axios  
- AsyncStorage  
- JWT Authentication  
- Laravel API (Backend)  
- MySQL (Database)
